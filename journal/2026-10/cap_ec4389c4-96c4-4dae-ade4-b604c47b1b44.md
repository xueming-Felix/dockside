## Content

Two ways to run the dashboard:

A) Already running on the Mac mini against the deployed actor, open to the LAN. If your laptop is on the same network as the Mac mini (10.0.0.x): http://10.0.0.172:7110 (sanity check: http://10.0.0.172:7110/api/health). I just seeded the cloud actor pier9-2026-10-31 at 08:00, 60x, so the clock is moving and the 08:30 arrival-check alarm will have fired by the time you look.

B) On your own laptop (needs Bun only; the generated Terse client is now committed, no terse CLI required):
```
git pull
printf 'TERSE_ACTOR_URL=https://api.useterse.ai/cmvwslt4400u1jy2a800ykfka/actors\nTERSE_API_KEY=<your token>\n' > actor/.env.cloud
cd dashboard && bun install && bun run build && bun run start:cloud
```
then open http://127.0.0.1:7110. Dev mode with hot reload instead: `bun run server:cloud` in one terminal, `bun run dev` in another, open http://127.0.0.1:5173.

To make the board move from any machine with that .env.cloud:
```
cd actor && set -a && source .env.cloud && set +a
bun scripts/drive.ts     # collision, swap, arrival, eta change, door 5 down, counter
bun scripts/seed.ts      # reset to 08:00
bun scripts/peek.ts      # print the actor's state
```
